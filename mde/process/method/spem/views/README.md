# SPEM Process Views

This directory is the single home for PlantUML views of the MODRISS process.
The diagrams visualize the formal content in the parent SPEM package and the
executable JSON contracts in [`../../../definitions/`](../../../definitions/).

- `lifecycle.puml`, `release-cycle.puml`, `operations-flow.puml`,
  `model-driven-increment.puml`, and `change-routing.puml` explain the
  integrated lifecycle and its coordination mechanisms.
- `end-to-end-process.activity.puml` shows the integrated executable process.
- `cim-process.activity.puml`, `pim-process.activity.puml`,
  `psm-process.activity.puml`, and `artifact-process.activity.puml` show the
  child modeling and readiness processes.

The catalog and synchronization rules are documented in
[`../diagram-catalog.md`](../diagram-catalog.md).
