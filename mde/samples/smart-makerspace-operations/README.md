# Smart Makerspace Operations Case Study

This directory is an executable end-to-end MODRISS case study for a deployable workshop demo.

## Model pipeline

1. [`01-cim-modeling-guide.md`](./01-cim-modeling-guide.md)
2. [`smart-makerspace.cim.xmi`](./smart-makerspace.cim.xmi)
3. [`smart-makerspace.draft.pim.xmi`](./smart-makerspace.draft.pim.xmi), generated by CIM-to-PIM ETL
4. [`02-pim-refinement-guide.md`](./02-pim-refinement-guide.md)
5. [`smart-makerspace.refined.pim.xmi`](./smart-makerspace.refined.pim.xmi)
6. [`smart-makerspace.draft.awspsm.xmi`](./smart-makerspace.draft.awspsm.xmi), generated by PIM-to-PSM ETL
7. [`03-psm-refinement-guide.md`](./03-psm-refinement-guide.md)
8. [`smart-makerspace.final.awspsm.xmi`](./smart-makerspace.final.awspsm.xmi)
9. [`generated-project/`](./generated-project/), generated by the AWS PSM model-to-text tool
10. [`04-artifact-completion-guide.md`](./04-artifact-completion-guide.md)

Intermediate models are retained deliberately so workshops can compare generated drafts with the
modeler's reviewed decisions at each abstraction level.
