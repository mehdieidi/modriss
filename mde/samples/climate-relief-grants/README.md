# Climate Relief Grants Case Study

This directory is an executable, end-to-end MODRISS modeling case study.

- [`cim-modeling-guide.md`](./cim-modeling-guide.md) describes the business case and the exact
  workbench sequence for building the CIM model.
- [`climate-relief-grants.cim.xmi`](./climate-relief-grants.cim.xmi) is the resulting CIM instance.
- [`climate-relief-grants.pim.xmi`](./climate-relief-grants.pim.xmi) is generated by the repository's
  CIM-to-PIM ETL transformation.
- [`pim-refinement-guide.md`](./pim-refinement-guide.md) explains how a modeler reviews and completes
  that generated PIM.

The guides use stable model IDs in backticks. These IDs make every instruction and connector
unambiguous and allow the prose, XMI, validation reports, and transformation traces to be compared.
