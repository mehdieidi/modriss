# PIM-to-AWS-PSM Transformation Test Coverage

This document traces semantic test coverage for the PIM-to-AWS-PSM ETL profile in `mde/transformations/pim-to-awspsm`.

Coverage status: **100% of direct ETL rules and helper EOL rule families are exercised by semantic tests** in `PimToAwsPsmEtlRegressionTest`.

## Bugs Fixed

| Area                           | Fix                                                                                                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| Missing implementation profile | `createLambdaCodeConfig` now handles undefined `implementationProfile` when deriving ZIP `codeUri`.                             |
| Physical name collision        | `physicalName` no longer substrings beyond the seed length when adding numeric suffixes.                                        |
| Multi-valued model tags        | Lambda image URI lookup now iterates `modelTags` entries instead of splitting the whole multi-valued collection.                |
| Trigger resolution             | `resolveTriggers` now uses the metamodel-correct `Trigger.function` opposite reference and supports `DataChangeStream` sources. |

No `.emf` metamodel changes were made.
