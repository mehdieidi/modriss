# PIM model root

`PIMModel` is the aggregate root of one provider-independent architecture. Its containments hold the reusable architecture objects that may be connected from several modules, including services, deployment units, schemas, event types, policies, flows, data-access records, human tasks, external endpoints, principals, secrets, traceability, and readiness evidence.

Containment at the root does not imply that every element belongs to the same service or release. Service ownership is expressed through service opposites and `ServiceElementMembership`; release composition is expressed through `DeploymentUnit.contains`. This distinction prevents lifecycle ownership from being inferred merely from serialization structure.

Source: `mde/metamodels/pim/pim-root.emf`.

## `PIMModel`

The root of one provider-independent serverless architecture. It collects deployment structure, compute, APIs, integrations, data, contracts, workflows, policies, security, configuration, traceability, and readiness evidence.

Direct supertypes: `TraceableElement`. Inherited attributes and marker capabilities are documented in the [shared kernel](../shared-kernel.md); this section lists every attribute declared by this class.
