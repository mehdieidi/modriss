# Shared kernel reference

The shared kernel supplies the cross-cutting vocabulary inherited by CIM, PIM, and AWS PSM elements. A class page in a DSML module lists its directly declared attributes; follow its supertype here for identity, traceability, lifecycle, expressions, readiness, and common value objects.

Source: `mde/metamodels/shared/kernel.emf`.

## Marker interfaces

Marker interfaces do not declare attributes. They identify capabilities used by the metamodel and transformations, such as deployability, invocation, routing, policy targeting, or configuration.

`DeployableElement`, `InvocationSource`, `InvocationTarget`, `FunctionTarget`, `WorkflowTarget`, `SubscriptionTarget`, `RoutingTarget`, `FlowEndpoint`, `ProtectedResource`, `PolicyTarget`, `DataAccessTarget`, `ExternalCallTarget`, `EnvironmentTarget`, `CredentialRequirementLike`, `RouteEndpoint`, `EventCarrier`, and `ConfigurableElement`.
