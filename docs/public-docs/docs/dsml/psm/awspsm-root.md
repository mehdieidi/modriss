# AWS PSM model root

The AWS PSM root is the deployment-oriented container. It owns stages, SAM stacks, AWS policies, documents, and the derived resource index.

Source: `mde/metamodels/psm/awspsm-root.emf`.

## `AwsPsmModel`

The root of one AWS platform-specific design. It owns AWS stages, SAM stacks, resource objects, policies, documents, and explicit integration views that can be rendered into deployment artifacts.

Direct supertypes: `TraceableElement`. Inherited attributes and marker capabilities are documented in the [shared kernel](../shared-kernel.md); this section lists every attribute declared by this class.

### Relationships

| Relationship                                  | Kind and multiplicity              | Meaning in the model                                                                                                                                            |
| --------------------------------------------- | ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `stages` → `AwsStage`                         | containment, [+]                   | The deployment environments through which this model is promoted. Each stage supplies account, region, approval, parameter, and tagging choices for its stacks. |
| `stacks` → `SamStack`                         | containment, [+]                   | The SAM/CloudFormation deployment units owned by the model. Resources acquire deployable scope by belonging to one of these stacks.                             |
| `samGlobals` → `SamGlobals`                   | containment, [?]                   | Optional shared SAM properties applied across functions, APIs, HTTP APIs, and state machines.                                                                   |
| `namingPolicy` → `AwsNamingPolicy`            | containment, [?]                   | The model-wide rules used to assess logical identifiers and provider-visible names.                                                                             |
| `taggingPolicy` → `AwsTaggingPolicy`          | containment, [?]                   | The required and reserved tag rules applied across AWS resources.                                                                                               |
| `securityBaseline` → `AwsSecurityBaseline`    | containment, [?]                   | The minimum encryption, public-access, logging, tracing, and wildcard-policy posture expected from the deployment.                                              |
| `traceModel` → `TraceModel`                   | containment, [?]                   | The trace links connecting AWS PSM elements with their source-model elements and generated outcomes.                                                            |
| `readiness` → `ProductionReadinessAssessment` | containment, [?]                   | The production-readiness assessment attached to this provider-specific design.                                                                                  |
| `documents` → `StructuredDocument`            | containment, [*]                   | Structured supporting material kept with the PSM, such as contracts or engineering records consumed by generation.                                              |
| `relationshipViews` → `AwsRelationshipView`   | containment, [*]                   | Cross-service connection records that gather several resource references into one inspectable integration path.                                                 |
| `allResources` → `AwsResource`                | reference; derived; read-only, [*] | A derived, read-only index of every `AwsResource` contained through the model's stacks. It is a navigation aid rather than a second ownership location.         |
