# Modless Landing

Static marketing site for Modless: product overview and an animated case-study demo.

## Run locally

```bash
python -m http.server 8083 --directory apps/landing
```

Open <http://127.0.0.1:8083>. With Docker Compose, the landing service is exposed on port **8083**
by default.
